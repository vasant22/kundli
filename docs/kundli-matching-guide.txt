Work in the phases below, IN ORDER. After each phase, run/test it, tell me what you did, then move to the next phase. Do not skip any phase. Verify every lookup table (nakshatra lists, sign lords, friendship tables) against a published classical source before using it — do not guess values.
 
## PROJECT GOAL
A new page (e.g. /match/ or match.html) where a visitor enters Boy's birth details, then Girl's birth details (two-step form, one person per screen, like the existing single-kundli form), and gets a bilingual Ashtakoot Guna Milan (36-point) compatibility report plus a Mangal Dosha (Kuja Dosha) check for both. All calculation stays in the browser — no backend, no new dependency beyond what already exists.
 
## PHASE 1: Reuse existing setup
- Add a new route/page in the existing Vite project: src/match.js (or equivalent), match.html entry, linked from the main page's navigation.
- Import and reuse the existing astro.js calculation function so that from a birth date/time/place you get the same planet+ascendant data object already used for the single Kundli (rashi, nakshatra, pada, house, retrograde for all 9 grahas, and the Ascendant).
- Reuse geocode.js (Open-Meteo place search), timeutil.js (UTC/Julian Day conversion), and i18n.js string patterns — extend i18n.js with new matching-specific bilingual strings rather than creating a parallel file.
 
## PHASE 2: Two-step input form (matches existing screenshot style)

- Bilingual language toggle carries over from the main site.
 
## PHASE 3: Ashtakoot Guna Milan calculation (src/ashtakoot.js)
Implement all 8 kootas using boyData.moon (rashi + nakshatra + pada) and girlData.moon. For each koota, verify the lookup table against a classical/published reference before coding it in; do not invent values.
1. Varna (1 point max): Classify each Moon-rashi into Varna (Brahmin/Kshatriya/Vaishya/Shudra) using the standard classical mapping. Score 1 if boy's Varna >= girl's Varna in the traditional hierarchy, else 0.
2. Vashya (2 points max): Classify each Moon-rashi into one of the 5 Vashya groups (Chatushpada, Manava, Jalachara, Vanachara, Keeta). Score per the standard Vashya compatibility table (full 2, half 1, or 0 depending on the pair).
3. Tara / Dina (3 points max): Count nakshatras from boy's to girl's Moon nakshatra and girl's to boy's (mod 27, using the standard 1-9 Tara groups: Janma, Sampat, Vipat, Kshema, Pratyak, Sadhaka, Vadha, Mitra, Parama-Mitra). Score per the standard table (0, 1.5, or 3) using both directions and averaging per the classical method.
4. Yoni (4 points max): Map each nakshatra to its Yoni animal (14 yonis) and use the standard Yoni compatibility matrix to score 0 to 4.
5. Graha Maitri (5 points max): Determine the ruling planet (lord) of each Moon-rashi, use the classical planetary friendship table (friend/neutral/enemy) to score 0, 1, 3, 4, or 5 per the standard rules (including same-lord and mutual-friend special cases).
6. Gana (6 points max): Classify each nakshatra into Deva/Manushya/Rakshasa Gana, score via the standard Gana compatibility table (0, 1, 4.5, 5, or 6 depending on which combination).
7. Bhakoot / Rashi (7 points max): Compute the rashi distance (1-12) both ways between boy's and girl's Moon-rashi. Score 0 for the classical dosha distances (6-8 and 2-12 pairs), else 7 — but implement the standard exceptions where Bhakoot dosha is cancelled if the rashi lords are the same or mutual friends (do not just apply a flat rule; check the classical exception list).
8. Nadi (8 points max): Classify each nakshatra into Aadi/Madhya/Antya Nadi. Score 0 if same Nadi (Nadi dosha), else 8. Note the classical exception cases where same-Nadi is not considered a dosha (e.g. same nakshatra but different pada in certain cases) — implement only if you can verify from a classical source, otherwise apply the straightforward same-Nadi=0 rule and note the simplification in comments.
 
Sum all 8 for a total out of 36. Return a structured object with each koota's name (Hindi+English), points scored, max points, and a one-line reason/explanation for why that score was given (e.g. "Same Nadi (Antya-Antya)" / "समान नाड़ी (अंत्य-अंत्य)").
 
## PHASE 4: Mangal Dosha (Kuja Dosha) check (src/mangaldosha.js)
- For EACH person independently: check whether Mars falls in house 1, 2, 4, 7, 8, or 12 counted from the Ascendant (standard rule) — note some traditions also check from the Moon; implement the Ascendant-based version as primary and label it clearly.
- If Mars is in one of those houses, flag Mangal Dosha = true for that person, and note the house number.
- Implement standard cancellation (Dosha-nivaran) rules — e.g. Mars in own sign or exaltation, Mars aspected/conjunct certain grahas, both partners having Mangal Dosha (mutual cancellation) — verify each cancellation rule against a classical source before including it; if uncertain about a specific rule, omit it and note in comments rather than guessing.
- If BOTH have Mangal Dosha, show a note that mutual presence is a classical cancellation factor.
- Output bilingual: dosha present/absent for each person, which house, and any applicable cancellation note.
 
## PHASE 5: Result / report page

- An interpretation band below the total, using the standard classical thresholds (e.g. below 18 = not recommended, 18-24 = average, 24-32 = good, 32-36 = excellent) — verify these threshold numbers against a published reference before using them.
- A separate Mangal Dosha section (from Phase 4) below the Ashtakoot table.
- A short bilingual disclaimer: this is a traditional Ashtakoot score, not a complete astrological judgement, and other factors (full chart, dashas, dosha severity) should be considered by a knowledgeable astrologer for a final decision.
- Buttons: "Download as PNG/PDF", "Print", same style as the existing single-Kundli results page.
