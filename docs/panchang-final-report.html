पंचांग

आज का पंचांग — होमपेज कार्ड से live पेज तक

तिथि, नक्षत्र, योग, करण, संवत्, मुहूर्त, तारा-चंद्रबल, सूर्योदय का चार्ट और नौ ग्रहों की तालिका — सब कुछ, पूरी तरह visitor के ब्राउज़र में (Swiss Ephemeris)। होमपेज के लिए छोटा कार्ड, और एक पूरा विस्तृत पेज। अब kundli.mybapuji.com/panchang/ पर live।

दायरा गणना-मॉड्यूल + विजेट + पूरा पेज चरण ११ (सब पूरे) कुल ख़र्च ≈ ६,००० अंक जाँचें ३६२ स्वचालित — सब पास

०१क्या बना

  • पूरा पंचांग पेज (kundli.mybapuji.com/panchang/) — जगह खोज, तारीख़ चुनने की सुविधा, और नौ खंड: आज का पंचांग · सूर्य-चंद्र गणना · हिंदू मास व वर्ष · अशुभ समय (८ मुहूर्त) · शुभ समय (अभिजीत) · दिशा शूल · चंद्रबल व ताराबल · सूर्योदय का लग्न चार्ट (उत्तर/दक्षिण/पूर्व-बंगाली तीन अंदाज़) · नौ ग्रहों की तालिका (राशि, अंश-मिनट-सेकंड, नक्षत्र, पद)। सब हिंदी + अंग्रेज़ी।
  • होमपेज विजेट (kundli.mybapuji.com/panchang-widget/) — mybapuji.com की होमपेज में iframe से लगने वाला छोटा कार्ड: जगह+तारीख़, तिथि, अमांत/पूर्णिमांत मास, दिन+विक्रम संवत्, नक्षत्र, योग, करण + "आज का पंचांग" बटन। रोज़ अपने-आप ताज़ा (रात 12 बजे के बाद भी ख़ुद बदलता है)।
  • साझा गणना-कोर — `sunrise.js` (सूर्योदय/सूर्यास्त/चंद्रोदय/चंद्रास्त), `panchang.js` (तिथि/नक्षत्र/योग/करण + संवत् + महीने + ऋतु + प्रविष्टे), `muhurat.js`, `panchang-extras.js` (दिशा शूल, तारा/चंद्रबल) — कुंडली ऐप के उसी engine और tables पर (कोई दोहराव नहीं)।
  • सुविधाएँ: Mumbai default (आपके निर्देशानुसार) · बदलाव के लिए जगह-खोज · हर जगह bilingual · चार्ट में अंश भी · mobile-first · कोई tracker नहीं।

०३ग्यारह चरणों की यात्रा

  1. ०१सूत्र-शोध: AstroSage + Drik से ~120 तारीख़ों का असली data लेकर हर नियम जाँचा — मुहूर्त-तालिकाएँ (सातों वार), संवत्, सम्वत्सर, प्रविष्टे, बंगाली चार्ट का layout।
  2. ०२सूरज-चाँद के समय: 4 शहर × 3 तारीख़ें — सूर्योदय/सूर्यास्त ±30 सेकंड; चंद्र ±2 मिनट; ध्रुवीय केस भी सँभाले।
  3. ०३मुख्य गणना: तिथि/नक्षत्र/योग/करण (अंत-समय सहित, "27:20:03" व "पूरी रात" शैलियाँ), तीनों संवत्, अधिक मास, ऋतु, चंद्र राशि। दो सूत्र सुधारे: विक्रम संवत् फाल्गुन पूर्णिमा के बाद बदलता है; ऋतु सायन (tropical) सूर्य से।
  4. ०४मुहूर्त: राहु काल, यमगंड, गुलिक (दिन के 8 हिस्से) + कुलिक, कंटक, कालवेला, यमघंट, दुष्ट मुहूर्त, अभिजीत (15 हिस्से)।
  5. ०५दिशा शूल + ताराबल (27 में से शुभ नक्षत्र) + चंद्रबल (शुभ राशियाँ) — हर तारीख़ की पूरी सूचियाँ मिलाई गईं।
  6. ०६नाम-सूचियाँ: 30 तिथि, 27 योग, 11 करण, वार, महीने, ऋतुएँ, 60 सम्वत्सर, मुहूर्त व दिशाएँ — हिंदी+अंग्रेज़ी, ~50 UI शब्द।
  7. ०७होमपेज विजेट: छोटा कार्ड, अपने-आप ताज़ा, transparent विकल्प, हिंदी/English।
  8. ०८पूरा पेज: नौ खंड, तीन चार्ट (नया "पूर्व भारतीय" चार्ट भी), नौ-ग्रह तालिका, साइट के nav में "पंचांग" link।
  9. ०९सत्यापन: 4 शहर × 3 तारीख़ें Drik से (सब ±2 मिनट में), 10-तारीख़ों की आपके हाथ की जाँच-सूची, README में सारे नियम।
  10. १०Deploy: GitHub पर हरा झंडा, दोनों पेज live; WordPress हिदायतें; एक छुपा bug (सिर्फ़ server पर दिखने वाला) पकड़ा और ठीक किया।
  11. ११अंतिम रिपोर्ट (यह पन्ना) + आधी-रात के auto-refresh की automatic जाँच आज रात।

०४चलाने के कमांड

# लोकल में देखना (dev server)
npm run dev          → http://localhost:5173/ तथा /panchang/ और /panchang-widget/

# पूरी जाँच-सूट (362 जाँचें)

# पंचांग जाँच-सूची दोबारा बनाना (सूत्र बदलने पर)
npm run panchang:validation

# deploy — बस यही: (GitHub ख़ुद test+build+bhejta है, ~1 मिनट)
git push origin main

०६जाँच-सत्यापन (कैसे भरोसा हुआ)

  • ३६२ स्वचालित जाँचें — सब पास (मुंबई/दिल्ली/वाराणसी/चेन्नई सहित)।
  • दिल्ली की 63 तारीख़ें AstroSage से — तिथि/नक्षत्र/योग/करण/संवत्/महीने/ऋतु/राशि + अंत-समय।
  • 4 शहर × 3 तारीख़ें Drik से — तत्व + राहु/यमगंड/गुलिक/अभिजीत/दुष्ट — सब ±2 मिनट में (असल में ~90 सेकंड)।

  • असली browser में हिंदी+अंग्रेज़ी दोनों में पेज व विजेट देखे; deploy के बाद live pages भी जाँचे।

०७ध्यान देने वाली बातें (ईमानदार सूची)

मुहूर्त-विभाजन (कुलिक, कंटक, कालवेला, यमघंट, दुष्ट): ये तालिकाएँ लोकप्रिय पंचांगों के असली नतीजों से मिलाकर निकाली गईं (सातों वार, दोनों साइटें) — शास्त्रीय ग्रंथ के नाम/श्लोक की पुष्टि बाक़ी है (README में flag)। आपके जानकार सेवा से मिलान करें तो बेहतर।
60 सम्वत्सर नाम: मानक सूची प्रयुक्त; क्रम-स्थान Drik की अपनी जानकारी से पक्का किया (शक 1948 = #40 पराभव)। हिंदी रूप कहीं-कहीं अलग लिखे जा सकते हैं (जैसे शोभकृत/शोभकृथ)।
पूर्व-भारतीय (बंगाली) चार्ट: इसका layout reference साइट के अपने चार्ट-code से decode किया (मेष ऊपर-बीच, उल्टी दिशा में, कोनों में त्रिभुज)। किसी छपी पंजिका से एक बार मिला लें तो और पक्का हो जाएगा।
छोटे स्वीकृत अंतर: तत्वों के अंत-समय में कोई संदर्भ-साइट से ~3 मिनट तक अलग दिख सकती है (दोनों संदर्भ साइटें भी आपस में 3–4 मिनट अलग होती हैं; हमारा मान Drik के ~1 मिनट के पास है)। "प्रविष्टे" में AstroSage की 2 जगह की विचित्रता व 29-03-2025 का करण-किनारा जान-बूझकर छोड़े गए (README में विस्तार)।
